# Author's English

A Claude Code skill that turns choppy "AI English" into the kind of flowing, plain storytelling people keep listening to, for
video scripts, voice-overs, captions, titles and descriptions.

Most AI drafts read like a stack of bricks, short sentence after short sentence, and every full stop gives a half-watching viewer
another chance to swipe away. This skill writes at the third of three levels, where each sentence carries the listener into the
next one with the feeling inside the line:

| Level | Example |
|---|---|
| AI English | I woke up. Saw brush. Put brush inside. Saw cavity. I was shocked. |
| Normal English | I woke up and grabbed my brush to brush my teeth. I was about to brush when I saw a cavity on my tooth. |
| Author's English | As usual I got up to brush my teeth, but my heart jumped when I noticed a whopping cavity on my tooth. |

The full rules, the before and after pairs from real films and the checklist are in [SKILL.md](SKILL.md).

## Install

```bash
git clone https://github.com/Ishaan-Gpt/author-english ~/.claude/skills/author-english
```

Claude Code picks it up on the next session and loads it whenever you ask for a script, a voice-over or a rewrite that "sounds AI".
